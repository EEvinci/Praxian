# 公私分库与发布约定

Praxian 保存可公开的知识与实践；Evincian 保存个人记忆。公开 GitHub 仓库中的草稿、附件、提交历史同样可见，`publish: false` 不能隐藏已经提交的源码。

## 整理次序

1. 先判断文章主要围绕通用知识还是个人经历。
2. 对混合内容，个人原文保留在 Evincian；提炼通用方法后另写公开稿，保留来源与适用边界。
3. 检查正文、图片、链接和文件名是否含个人或他人隐私、工作保密信息与凭据。
4. 根据根目录《标签库》赋予主领域与二级主题。
5. 公开稿的引用链接只能指向公开内容；未发布的双链要处理后再发布。
6. 将该文件的精确路径加入 Git 白名单，再明确暂存该文件；不使用强制添加去跳过忽略规则。

原有目录暂时保留，以免破坏双向链接。原库快照位于 Evincian，仅作备份，不应作为已经发生的履历或事实证明。带有代拟、推演或假设说明的原文必须保留说明。

## 本次公开范围

根目录 README、标签库、协作约定、本使用说明、新知识笔记模板，以及已核对的《品味如何培养：从欣赏好作品到做出好作品》。其余旧笔记和附件仅保留在本地，不在本次公开提交范围。

## 后续博客

博客发布、自动同步和知识图谱仍待另行确认方案。本次不编写相关程序，不新增后台任务，不自动发布笔记。公开 GitHub 仓库的更新也不会自动变成博客文章。
