# Praxian · 知行库

**What I learn and do. — 我所学的，以及我所实践的。**

Praxian 是 Evinci 的工作与学习知识库，用来积累知识、方法、实践和可复用的判断。

## 名称的含义

Praxian 是一个自造名称，取意于 *praxis*（实践、把知识付诸行动），以 `ian` 结尾，呼应 Obsidian。它强调学习与实践之间的往返：理解一个问题，尝试解决它，用结果修正认识，再把经验整理成可复用的知识。它不是某个既有英文词的标准释义。

与之配对的是 **Evincian · 自我档案**。Praxian 回答“我知道什么、能做什么”；Evincian 回答“我是怎样的人、经历了什么、正在成为谁”。数字分身依托后者的个人记忆逐渐形成。

## 内容边界

- 收录：AI 与自动化、产品与设计、数学与教育、知识与表达、商业与职业、思维与方法。
- 个人日记、健康数据、私人关系、履历细节与个人偏好归入 Evincian。
- 通用的学习方法属于这里；我的学习习惯与效果记录属于 Evincian。
- 可复用的职业方法属于这里；求职沟通、薪资与个人职业决策属于 Evincian。
- 工作资料仍需检查保密性；“工作与学习”不意味着材料天然可以公开。
