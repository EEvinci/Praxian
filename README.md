## 名字背后

Praxian 取意于 *praxis*，即把知识付诸实践；`ian` 的结尾呼应 Obsidian。这是一个自造名称，寄托着学习、行动与修正之间的往返。

与它相伴的 Evincian 是私人自我档案：一个积累知识，一个保存个人记忆。
