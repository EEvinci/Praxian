## 热词与问题

| 口语入口 | 往哪里找 | 注意区别 |
| --- | --- | --- |
| 内耗、精神内耗 | 心理学/应对与复原/内耗 | 是宽泛体验描述，不等于一个诊断或单一机制 |
| 上头、停不下来 | 心理学/动机与习惯/奖励让人上头 | 看奖励与强化，不把所有投入都说成成瘾 |
| 边界感、讨好 | 心理学/人际与依恋 | 界限、共情、讨好是不同问题 |
| 情绪价值 | 心理学/人际与依恋/情绪价值 | 区分支持行为、个人需求和网络用法 |
| 第一性原理、祛魅、主体性 | 哲学/哲学与热词 | 先解释语境，不把口号当成论证 |
| 长期主义、反脆弱 | 思维与方法/做选择 或 看整个系统 | 作为候选检索词，尚不是正式三级标签；需结合具体文本再归类 |

## 旧路径对照

- 产品与设计/视觉与审美/品味训练 → 产品与设计/看着舒服/品味怎么练。
- 产品与设计/用户研究/反馈验证 → 产品与设计/看用户怎么用/反馈有没有证据。
- 数学与教育/数学概念/条件概率 等专门知识点：旧文不删除，新的考研数学笔记在 MathLab 按实际知识点建档。
- 其他旧三级标签保留在旧笔记中，后续逐篇阅读再替换，不机械批量套用。
