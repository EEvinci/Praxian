# 标签词表

六个一级领域，两级主题。让标签帮助找回内容，保持名称简短、含义稳定。

## 领域与主题

| 一级领域 | 二级主题 |
| --- | --- |
| AI与自动化 | 大模型、智能体、检索增强、工作流、评估与可靠性、AI落地、具身智能 |
| 产品与设计 | 产品方法、用户研究、交互设计、视觉与审美、应用构建 |
| 数学与教育 | 数学概念、解题方法、教学设计、课程准备、学习评价、教育AI |
| 知识与表达 | 知识管理、学习方法、阅读研究、写作表达、内容创作 |
| 商业与职业 | 职业发展、作品集、商业模式、内容变现、投资与风险 |
| 思维与方法 | 逻辑与证据、决策判断、系统思维、项目管理、复盘方法 |

## 使用方式

`areas` 选择一级领域，首项为主领域，最多两个。`tags` 使用“一级领域/二级主题”，通常 1—3 个，最多 4 个。

例如，[培养品味](../Library/Articles/培养品味.md) 使用：

```yaml
areas:
  - 产品与设计
  - 知识与表达
tags:
  - 产品与设计/视觉与审美
  - 知识与表达/内容创作
```

工具、平台、人物和项目名分别记录在 `tools`、`keywords`、`people`、`projects` 等属性中。笔记用途与进度使用 `type` 和 `status`，不再重复成为主题标签。

## 保持简洁

先复用已有主题，再考虑新词。同义词合并到已有标签；新主题反复出现，或已明确成为长期关注时，再进入正式词表。

默认不使用第三级。目前正式三级标签：**无**。确有检索需求时，先确认，再登记完整的一、二、三级定义和迁移范围。

个人经历、健康与偏好记录归入私人自我档案，不因为涉及某个知识主题而直接公开。
