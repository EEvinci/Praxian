# 标签词表

三级分别回答：属于哪个领域、研究哪个主题、具体讨论什么。第三列用分号区分可选标签，第四列限定收录范围。完整标签由前三列组合，例如 `数学与教育/数学概念/条件概率`。

## 思维与方法

| 二级主题 | 三级知识点 | 描述范围 |
| --- | --- | --- |
| 逻辑与证据 | 因果与相关；样本偏差；数学证明；证据等级 | 相关不能替代机制、选择过程、演绎前提、出处与推断强度 |
| 决策判断 | 机会成本；区间估计；反事实；停止条件 | 放弃的替代选项、不确定范围、假设比较、何时退出 |
| 系统思维 | 反馈回路；任务依赖；瓶颈约束 | 行动如何改变后续状态、先后顺序、限制总体产出的环节 |

| 复盘方法 | 失败样本；后见偏差；预测校准 | 留下错误与原因、保留当时未知信息、预测和结果对照 |

## 标注示例

```yaml
areas:
  - 产品与设计
tags:
  - 产品与设计/视觉与审美/品味训练
  - 产品与设计/用户研究/反馈验证
```

上例对应《培养品味》。条件概率文章可用 `数学与教育/数学概念/条件概率`；重试文章可用 `AI与自动化/工作流/幂等重试`。

每篇通常选择 1—3 个三级标签，只标正文真正展开的内容。领域名与二级主题不再另作重复标签。工具名、作者与项目写属性；进度写 status。跨领域按文章的主要用途选择，不把同一段内容重复归类。

当前词表是可用分类，不表示对应知识点已有文章或已经掌握。新知识点先写清定义与对应笔记，再登记入表；同义词优先合并。已有旧标签尚未全库替换。
