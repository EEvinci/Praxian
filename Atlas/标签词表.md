# 标签词表

按“领域 / 话题 / 具体问题”收录。标签先让人看懂，再用标准术语帮助检索。表格中用分号分开的词各是一个三级标签，不是必须同时勾选的清单。

例如 `AI与自动化/Agent智能体/多Agent分工`。英文缩写、中文译名及网络说法另见 [关键词入口](关键词入口.md)，同一个概念不建立两套标签。

| 先做小版本 | MVP先做什么；PRD说清需求；Prototype验证交互；Feature-Creep越做越多 | 最小可用产品、需求文档、原型和范围膨胀 |

## 思维与方法

| 二级话题 | 三级标签 | 讨论什么 |

## 心理学

从心理过程、个体差异、关系情境到研究方法组织。口语标题是入口，右栏保留明确概念；网络词不作为诊断，也不自动等同于学术概念。

| 二级话题 | 三级标签 | 概念与边界 |
| --- | --- | --- |
| 注意与记忆 | 为什么走神；工作记忆装不下；为什么会忘；记忆也会改写 | 注意分配、工作记忆、遗忘与重构 |
| 情绪怎么运作 | 情绪从哪来；焦虑在提醒什么；情绪怎么调；压力怎么积累 | 情绪评价、焦虑、调节与压力；不凭标签判断疾病 |
| 动机与习惯 | 为什么拖延；奖励让人上头；习惯怎么养；外部要求与自愿 | 拖延、强化、习惯、内外在动机；拒绝万能归因 |
| 认识自己 | 自我评价怎么来；自尊为什么波动；我能不能做到；人格与处境 | 自我概念、自尊、自我效能、人格及情境差异 |
| 人际与依恋 | 亲密关系怕什么；边界感；共情与讨好；情绪价值 | 依恋、个人界限、观点采择与支持；这些词不是彼此同义词 |
| 群体与影响 | 为什么会从众；权威怎么影响人；群体如何极化；刻板印象 | 从众、服从、群体极化和社会分类 |
| 判断的偏差 | 确认偏误；损失更扎心；以为别人都看我；给行为找原因 | 确认偏误、损失厌恶、聚光灯效应与归因 |
| 成长与变化 | 不同阶段的需要；能力怎么发展；经历如何塑造人 | 生命周期、认知与社会情感发展；避免阶段决定论 |
| 应对与复原 | 内耗；反刍停不下来；自我关怀；遇挫怎么恢复 | 内耗是宽泛体验词，另辨反刍、自责和应对资源；不直接等同某种障碍 |
| 研究怎么看 | 量表测到了什么；相关不能推因果；实验能否推广；效应有多大 | 测量、研究设计、外部效度与效应大小 |

个人症状、关系记录与健康材料保存在 Evincian；这里收录公开知识与阅读理解。

## 哲学

按认识、存在、行动与价值、社会以及传统组织。先提出问题，再区分论证和立场，避免把一句流行话当成哲学结论。

| 二级话题 | 三级标签 | 概念与边界 |
| --- | --- | --- |
| 逻辑与论证 | 理由能推出结论吗；偷换了什么概念；反例推翻什么；必要还是充分 | 推理有效性、概念歧义、反例与条件关系 |
| 知识与真理 | 我凭什么知道；相信不等于知道；怀疑到哪里；真理怎么理解 | 认识论、知识与证成、怀疑论和真理观 |
| 存在与现实 | 什么算存在；世界只有物质吗；事情为什么发生；还是同一个我吗 | 本体论、物理主义等立场、因果性与同一性 |
| 心灵与意识 | 意识是什么；心和脑是什么关系；AI能理解吗；我有自由意志吗 | 心灵哲学、意识、理解与自由意志；不预设争论已解决 |
| 伦理与选择 | 结果重要还是原则；怎样才算好人；关心谁的利益；道德冲突怎么选 | 后果论、义务论、美德伦理、关怀伦理及具体困境 |
| 社会与政治 | 公平等于平均吗；自由的边界；规则凭什么有效；权力如何运作 | 分配正义、自由、政治正当性与权力分析 |
| 科学与方法 | 科学怎么划界；证伪能说明什么；理论如何更替；模型不等于现实 | 科学划界、证伪思想、范式与科学实在论问题 |
| 意义与生活 | 人生有固定答案吗；荒诞感；真实地生活；斯多葛怎么理解 | 意义、存在主义相关问题、真实性与斯多葛传统；不是通用鸡汤 |
| 语言与解释 | 话是什么意思；语境改变什么；解释有没有边界 | 意义、指称、语用与解释学问题 |
| 中国哲学 | 儒家的修身；道家的自然；佛教的无我；知行怎么相连 | 不同传统中的概念及文本语境，不把学派合成一套答案 |
| 哲学与热词 | 第一性原理；祛魅；主体性；工具理性 | 追问基本前提、理解理性化语境、行动主体与手段理性；保留词义差异 |

## 标注与维护

每篇通常选 1—3 个正文真正展开的三级标签。英文里的空格在标签中用连字符，如 `Human-in-the-loop人工接管`。缩写和译名通过关键词入口查到正式路径，不再额外贴一串同义标签。该文档没有自动别名映射功能。

热词用于检索和发问，不代替解释。新词出现时先判断是否只是旧概念的新说法；需要新增时补上范围及对应文章。标签存在不代表已有文章或已经掌握。
